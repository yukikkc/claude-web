# Live Freely ブログ記事執筆スキル

ブログ「Live Freely」（https://live-freely-22.com/）の記事を書くためのスタイルガイド。

## ブログの基本情報

- **ブログ名**: Live Freely
- **タグライン**: 仕事と子育てをしつつ、自己実現をする努力をしながら、自由に生きる様子を発信していきます。
- **運営者**: ゆき（ゆきママ / @yukiMUM22）
  - 理学療法士として11年勤務ののち、出産を機にWeb制作コーダーへ転身
  - 2児のママ（記事執筆時点の子どもの年齢は文脈に合わせる）
  - 東京在住、自宅保育をしながらフリーランスで在宅ワーク（月収20〜30万円）
- **主なカテゴリ**: Web制作 / 在宅ワーク / 子育て / 時短テクニック
- **想定読者**: 子育て中のママ。特に「在宅ワークしたい」「自宅保育で忙しい」「時間もお金も工夫したい」層。専門用語は噛み砕いて説明する。

## 文体・口調のルール

1. **書き出しは必ず挨拶から**: 「こんにちは！ゆきです！」で始める。その直後に、記事を書くきっかけになった実体験・エピソードを1〜3文で語る。
2. **です・ます調**のカジュアル寄り。堅い敬語にしすぎない。
3. **「！」を多め**に使う。驚き・共感・テンションの高さを素直に出す（ただし1文に1つまで）。
4. **一人称は「私」**。夫は「夫」、子どもは「子どもたち」「息子/娘」など。
5. **読者への語りかけ**を入れる：「〜じゃないですか？」「〜なママも多いのではないでしょうか？」「ぜひチェックしてみてくださいね！」など。
6. **本音・感情をそのまま書く**：「正直、驚きました！」「これは知らないと損です…！」「思いのほか使えた」のような率直な表現がこのブログの持ち味。
7. 体験談ベース。制度やサービスの紹介でも「私が調べた/使ってみた」という一次視点で書く。
8. 数字は具体的に出す（「月収30万円」「1時間2,500円」など）。全角数字と半角数字はどちらでもよいが記事内では統一する。

## タイトルの付け方

以下のパターンを組み合わせる：

- **【】で属性やフックを先頭に**：「【子育てママにおすすめ】」「【2025年版】」「【知らないと損】」
- **具体的な数字**を入れる：「月収30万円」「サイト15選」「最大36万円」
- **感嘆・体験談の語り口**：「実はこんなにある！」「〜してみたら、思いのほか使えた話」
- 例：
  - 「自宅保育で月収３０万円！フリーランスママのリアルな1日スケジュール！【子育てママが在宅ワークで稼ぐ方法】」
  - 「【子育てママにおすすめ】AIでライフプラン表作ってみたら、思いのほか使えた話」
  - 「【2025年版】実はこんなにある！未経験OK！在宅ワークの見つけ方〜自宅保育しているママにもオススメのサイト15選〜」

## 記事の構成テンプレート

1. **挨拶＋きっかけエピソード**（こんにちは！ゆきです！〜）
2. **この記事でわかること**（箇条書き3〜5個。読者メリットを提示）
3. **本文**（H2見出しで区切る。H2の中は必要に応じてH3）
   - 制度・サービス紹介系なら：「〜とは？」→「いくらお得？」→「対象者・条件」→「使い方の流れ」→「比較・まとめ表」→「注意点」の順
   - 表で比較できるものは表にする
   - 重要ポイントは箇条書きや引用ブロックで目立たせる
4. **まとめ**（要点の箇条書き＋読者の背中を押すひとこと＋「ぜひ〜してみてくださいね！」）
5. 制度・お金系の記事は、末尾に「※本記事は◯年◯月時点の情報です。最新情報は公式サイトでご確認ください。」の免責を入れる

## 執筆ワークフロー

1. トピックについて最新情報をリサーチする（制度・お金系は公式サイトの情報を優先し、年度・金額・条件を確認する）
2. `articles/` ディレクトリに `articles/<slug>.md` として保存する（slugは英語ケバブケース）
3. 冒頭にタイトル（H1）、その下に本文。WordPressに貼りやすいMarkdownで書く
4. 事実（金額・時間数・条件）は出典を確認してから書く。不確かなものは「※最新は公式サイトで確認」と添える
5. 固有名詞（サービス名・制度名）は正式名称で書く
