# 朝の秘書 — セットアップ内容

毎朝・毎晩に自動起動する「秘書」の構成メモ。Routine(定期実行)は Claude Code on the web の
スケジュール機能(create_trigger)で作成する。作成されると各回は新しいセッションとして起動し、
完了時にスマホへプッシュ通知が届く。

## 構成

| いつ | 何をする | 通知 |
|---|---|---|
| 毎朝 7:00 JST(cron `0 22 * * *` UTC) | 朝ブリーフ生成: 今日の予定(Googleカレンダー)+ Notionの稼働案件 + Fiverrログインのリマインダー | プッシュ |
| 毎晩 20:30 JST(cron `30 11 * * *` UTC) | 明日の予定のまとめ + 夫に共有できるコピペ用メッセージ | プッシュ |

前提:

- Notion コネクタ: 接続済み。案件管理表 = `collection://ac9087ff-46a5-4bfb-b38f-0ccdf898af70`
- Google カレンダー コネクタ: claude.ai の設定 → コネクタ で有効化(未認証ならログイン)しておくこと
- Fiverr: 自動ログインはしない(規約違反・Bot検知によるアカウント凍結リスクのため)。
  朝の通知のリマインダーを見てスマホアプリを開けば「直近24時間オンライン」の条件は満たせる

## Routine 1: 毎朝の秘書ブリーフ(7:00 JST)

- name: `毎朝の秘書ブリーフ(7:00 JST)`
- cron_expression: `0 22 * * *`(UTC)
- create_new_session_on_fire: true / notifications: push

プロンプト:

```
あなたは朝の秘書です。Skillツールで「morning」スキルを起動し、日本語で朝のブリーフ(HTML 1枚)を作成してください。これは無人のスケジュール実行です。

設定:
- 言語: 日本語(見出し・本文すべて。日本語見出しにはシステムのserifを使い、Frauncesの埋め込みは省略してよい)
- タイムゾーン: Asia/Tokyo。「今日」はJSTで判定する。
- カレンダー: Googleカレンダーのコネクタが使えるなら今日の予定を1回取得して地形(terrain)を描く。使えない場合は穏やかな水平線を描き、下部に接続を促す1行だけ添える。
- Sections(Resolvedの下に以下の順で):
  1. 「稼働中の案件」 — Notionの案件管理表(データソース collection://ac9087ff-46a5-4bfb-b38f-0ccdf898af70)をSQLで1回照会する: 状態が「納品済」以外の行を納期昇順で取得し、サイト名(Notionページへのリンク)・クライアント名・状態・納期を一覧にする。納期超過または7日以内に納期が来る案件があれば、Needs attentionにも1行入れる。
  2. 「Fiverr」 — 固定の1行リマインダー: スマホのFiverrアプリを開いて今日のログインを済ませる(直近24時間オンラインのセラーとして検索に表示されるため)。
- 無人実行なのでコネクタ提案カードは出さず、質問もせず、ブリーフの描画のみ行う。
- 完成したらPlaywright(executablePath: /opt/pw-browsers/chromium)でスクリーンショットを撮って崩れがないか確認し、SendUserFileでHTMLとPNGを送付する(status: proactive、captionに今日の要点を1行で。Fiverrログインのリマインダーも一言添える)。
```

## Routine 2: 明日の予定の共有通知(20:30 JST)

- name: `明日の予定の共有通知(20:30 JST)`
- cron_expression: `30 11 * * *`(UTC)
- create_new_session_on_fire: true / notifications: push

プロンプト:

```
あなたは夜の秘書です。これは無人のスケジュール実行です。タイムゾーンはAsia/Tokyoで、「明日」はJST基準の翌日です。

やること:
1. Googleカレンダーのコネクタで明日の予定を1回取得する(終日予定も含む)。
2. 日本語で簡潔にまとめる: 冒頭に1行の要約(例「明日は予定3件、最初は10時から」)、続けて時刻順の箇条書き(時刻・件名・場所があれば場所)。
3. 最後に「共有用」として、夫にそのままLINE等でコピペして送れる短いメッセージ(2〜4行、絵文字は控えめ)を作る。
4. 予定がない場合は「明日は予定なし」と一言で伝える。

注意:
- カレンダーコネクタが使えない場合は「Googleカレンダー未接続のため取得できませんでした。claude.aiのコネクタ設定で有効化してください」とだけ伝える。
- 無人実行なので質問やコネクタ提案カードは出さない。ファイル生成も不要で、テキストの返答のみでよい。返答の冒頭に要約を書くこと(プッシュ通知に載るため)。
```

## スマホからの操作(Routine不要)

Claude アプリ / claude.ai/code からこのリポジトリのセッションを開いて話しかけるだけ:

- 「明日15時に○○さんと打ち合わせをカレンダーに入れて」→ Googleカレンダーに登録
- 「新しい案件を登録して。サイト名○○、クライアントは△△、納期は8/10」→ Notionの案件管理表に追加
- 「今の稼働案件を教えて」→ 案件管理表を照会して一覧

## 変更したいとき

セッションで「朝の時刻を6時にして」「夜の通知をやめて」などと伝えれば、
list_triggers / update_trigger / delete_trigger で変更・停止できる。
